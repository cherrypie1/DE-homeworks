Домашнее задание 26:
1. Решите задачу по проектированию системы IoT: Вы разрабатываете модель данных для системы "умного дома", которая собирает данные о температуре, влажности и потреблении энергии. Какую модель данных вы бы использовали, и почему?
(Ответ предоставьте в 3-4 предложения)
2. Задача по выбору модели данных для банковского приложения: Сравните графовую и реляционную модели данных для системы анализа транзакций. Опишите, в каких случаях каждая из них будет наиболее эффективной и почему.
(Ответ предоставьте в 3-4 предложения)

1.Система "умного дома" регулярно собирает данные с разного рода датчиков. Для анализа и хранения подойдет временная серийная модель данных. 
Эта модель эффективна для данных, которые изменяются со временем, обеспечивая высокую производительность при агрегации и запросах по временным интервалам. 

2.Реляционная модель данных хорошо подходит для хранения финансовых данных и обеспечивает целостность через ACID-транзакции, что важно для операций с счетами и отчетностью. 
Графовая модель эффективна при анализе связей, например для отслеживания цепочек транзакций между пользователями. 
Реляционная модель удобна для стандартных запросов и бухгалтерских расчетов, тогда как графовая — для визуализации и анализа взаимосвязей. Возможно гибридный подход сможет эффективно решить вопросы целостности данных и отслеживать цепочки переводов.
